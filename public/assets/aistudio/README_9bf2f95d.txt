EP ST. PIERRE NKOMBO WEBSITE
============================

Files:
- index.html: responsive trilingual school website (English, Kinyarwanda, French)
- exam.html: add the school's online exam file here to activate the exam button.

BEFORE PUBLISHING:
1. Replace sample news and gallery placeholders with school-approved content.
2. Confirm the school's official details, admissions requirements and public contact details.
3. Add the online exam file as exam.html.
4. Upload the contents of this folder to a static web host (for example Netlify, GitHub Pages or another hosting provider).
5. A public URL is created by the hosting provider. This folder itself is not yet online.

IMPORTANT:
- The contact form opens the visitor's email application; it does not save submissions online.
- This static starter website has no administrator login, database, or central student-submission system.
- Use school-approved photographs and obtain appropriate consent before publishing identifiable learners.
